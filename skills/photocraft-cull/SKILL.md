# Отбор кадров в PhotoCraft

Из папки со съёмкой получается короткий список кадров, которые стоит обрабатывать. У каждого кадра есть решение и причина. Ни один файл не удаляется и не переносится.

В PhotoCraft нет счётчика резкости, поэтому отбор идёт глазами в два прохода: сначала мелкие миниатюры на листах, потом кусок лица или вещи в полном размере у кандидатов. Если на компьютере есть `lightcraft-cli` и в съёмке больше 150 кадров, быстрее сработает скилл `lightcraft-cull`: он сам считает резкость и собирает похожие кадры в группы.

Перед началом прочитай `../photocraft-base/SKILL.md`. Команды сверь через `photocraft-cli commands --filter contactSheet`, `--filter detectFaces` и `--filter image.crop`.

## Что этот скилл не делает никогда

- Не удаляет, не переименовывает и не переносит файлы. Отбор состоит из копий.
- Не решает сам про кадры, где на товаре читается чужой логотип. Такие кадры идут в список «спросить».
- Не называет кадр резким, пока не посмотрел его кусок в полном размере.

## Шаг 1. Посмотри папку

1. Посчитай фото. Если их больше 150, предупреди человека, что отбор глазами займёт время.
2. Если ты не можешь открывать изображения, скажи об этом сразу. Без просмотра этот скилл не работает.
3. Создай рядом с папкой исходников папки `_отбор/листы` и `_отбор/резкость`.

## Шаг 2. Спроси только нужное

| Вопрос | По умолчанию |
|---|---|
| Сколько кадров оставить | от 3 до 5 на каждый образ или товар |
| Для чего съёмка | каталог: вещь целиком и резко. Соцсети: подходят и живые кадры с движением |

## Шаг 3. Листы с миниатюрами

Раздели список файлов по 12 и на каждую часть собери лист 4 на 3. Способ и все оговорки описаны в части А скилла `photocraft-proof-sheet`. Для отбора размеры такие:

```sh
photocraft-cli run --new '{"width":64,"height":64}' \
  --cmd file.automate.contactSheetII --params '{"input":["./исходники/IMG_0401.jpg","./исходники/IMG_0402.jpg"],"units":"pixels","width":2400,"height":1800,"resolution":72,"columns":4,"rows":3,"caption":true,"fontSize":28,"flatten":true}' \
  --out ./_отбор/листы/лист-01.jpg --quality 85
```

В `input` идут все 12 путей этой части. Под каждой миниатюрой стоит имя файла, по нему ты находишь кадр.

## Шаг 4. Первый проход по листам

Открой каждый лист и сделай три вещи:

1. Раздели кадры на образы или товары: соседние кадры с одной вещью это один образ.
2. Сразу отметь «нет» там, где брак виден даже мелко: закрытые глаза, вещь обрезана краем кадра, сильный смаз, в кадре край фона или посторонний предмет.
3. В каждом образе выбери кандидатов: вдвое больше, чем нужно оставить.

## Шаг 5. Проверь резкость кандидатов

Миниатюра резкость не показывает. Для каждого кандидата вырежи кусок в полном размере и посмотри на него.

Кадр с человеком. Найди лицо:

```sh
photocraft-cli run исходники/IMG_0412.jpg --cmd image.detectFaces
```

В ответе у лица есть `rect`: `[x, y, ширина, высота]`. Вырежи этот прямоугольник с запасом в половину его размера с каждой стороны:

```sh
photocraft-cli run исходники/IMG_0412.jpg \
  --cmd image.crop --params '{"x":1650,"y":700,"width":900,"height":900}' \
  --out _отбор/резкость/IMG_0412-лицо.png
```

Резкий кадр: видны ресницы и радужка глаза. Нерезкий: глаза и брови сливаются в пятна. Для каталога вырежи ещё кусок вещи на груди или по шву: фактура ткани должна читаться.

Предметный кадр. Лица нет, поэтому возьми кусок в центре предмета. Рамку предмета даёт `photocraft-cli run кадр.jpg --cmd layer.removeBackground`, поле `bounds`. Резкий кадр: видны строчка, фактура кожи или ткани, край подошвы.

Кандидатов одного образа сравнивай между собой: в работу идёт самый резкий из тех, что прошли шаг 6.

## Шаг 6. Что проверяешь глазами

| Проверка | Что считается браком |
|---|---|
| Глаза | закрыты или прикрыты наполовину |
| Лицо | неудачное выражение, рот на полуслове |
| Вещь в кадре | обрезана краем кадра |
| Посадка вещи | мятая или перекрученная так, что не видно крой |
| Руки | закрывают товар |
| Фон | виден край бумажного фона, стойки, провода |
| Чужие логотипы | читаются на товаре: кадр в список «спросить», решает человек |
| Смаз | лицо резкое, а вещь смазана движением |

Пятна и складки на фоне браком не считаются: их убирает скилл `photocraft-backdrop-clean`.

## Шаг 7. Решение по каждому кадру

Каждый кандидат получает решение и одну короткую причину: «берём», «запас», «нет» или «спросить». Запиши таблицу в `_отбор/отбор.md`:

| Файл | Образ | Решение | Причина |
|---|---|---|---|
| IMG_0412.jpg | синее платье | берём | лицо и платье резкие, вещь целиком |
| IMG_0413.jpg | синее платье | запас | рука закрывает карман |
| IMG_0431.jpg | бежевый тренч | нет | глаза закрыты |
| IMG_0460.jpg | кепка | спросить | читается чужой логотип |

Кадры, которые получили «нет» ещё на листах, запиши одной строкой на образ: сколько и почему.

## Шаг 8. Копии

Скопируй файлы. Никогда не переноси и не удаляй:

```sh
mkdir -p отбор/_запас
cp -n исходники/IMG_0412.jpg отбор/
cp -n исходники/IMG_0413.jpg отбор/_запас/
```

В PowerShell: `New-Item -ItemType Directory -Force отбор\_запас` и `Copy-Item исходники\IMG_0412.jpg отбор\`. Кадры «спросить» не копируй, пока человек не ответил.

## Шаг 9. Лист отобранного и отчёт

Собери лист из папки `отбор` скиллом `photocraft-proof-sheet` и покажи человеку вместе с таблицей. Жди «да» или правки.

Отчитайся:

1. Сколько кадров в папке, сколько образов.
2. Сколько «берём», «запас», «нет», отдельным списком «спросить» с причиной.
3. Где лежат `отбор/`, `_отбор/отбор.md` и лист.
4. Совет на следующую съёмку по самым частым причинам «нет»:

| Частая причина | Совет |
|---|---|
| Нерезкие кадры | короче выдержка или больше света, чаще проверять фокус по глазам |
| Пересвет на белых вещах | меньше мощность света или экспозиция на ступень ниже |
| Виден край фона | шире фон или ближе модель к центру |
| Закрытые глаза | снимать по два-три кадра на одну позу |
