# Фото на модели

Обрабатывает съёмку вещей на человеке: примерки, лукбук, фото для ленты. Задача простая: кадры ровные, светлые, одинаковые, а человек и вещь выглядят как в жизни.

Перед началом прочитай `../photocraft-base/SKILL.md`. Команды сверь через `photocraft-cli commands --filter`.

## Что этот скилл не делает никогда

- Не меняет фигуру, лицо, кожу, волосы человека. Не стройнит, не удлиняет ноги, не «омолаживает».
- Не меняет вещь: цвет, длину, посадку, складки от носки.
- Ничего не дорисовывает и не достраивает. Генеративных инструментов в PhotoCraft нет, и искать им замену не нужно.
- Не убирает людей и предметы из кадра закрашиванием.

Если человек просит что-то из этого списка, скажи прямо, что этот скилл так не делает, и предложи переснять кадр или подобрать другой.

Мелкие дефекты фона (пыль, пятно на стене, складка бумажного фона) и точечные дефекты кожи убираются вручную в окне PhotoCraft инструментом Spot Healing. Ты можешь составить список кадров, где это нужно, с описанием места.

## Шаг 1. Посмотри съёмку

1. Посчитай фото, открой шесть-восемь из разных мест папки.
2. Проверь, однородна ли съёмка по свету и фону. Если нет, раздели на группы.
3. Сразу отметь кадры, которые обработкой не спасти: нерезкие, с закрытыми глазами, с обрезанной вещью. Предложи человеку исключить их до обработки.
4. Если на вещах читаются чужие логотипы, скажи об этом: для публикации от имени магазина такие кадры могут не подойти.

## Шаг 2. Договорись о порядке

Назови порядок и спроси про необязательные шаги:

| Шаг | По умолчанию |
|---|---|
| Выровнять горизонт | только на заметно заваленных кадрах |
| Автоконтраст | да |
| Тени и света | слегка: тени 15, света 10 |
| Сочность | `vibrance` 10 |
| Резкость | лёгкая |
| Ровный фон | нет |
| Кадрирование под пропорцию | нет |

Спроси, для чего съёмка: каталог (строго и одинаково) или соцсети (можно теплее и контрастнее). Для соцсетей вид подбирается скиллом `photocraft-batch-look`, здесь остаётся только аккуратная основа.

## Шаг 3. Проба на одном фото

```sh
photocraft-cli run вход.jpg \
  --cmd image.autoContrast \
  --cmd image.adjustments.shadowsHighlights --params '{"shadowAmount":15,"highlightAmount":10}' \
  --cmd image.adjustments.vibrance --params '{"vibrance":10}' \
  --cmd filter.sharpen.unsharpMask --params '{"amount":50,"radius":1,"threshold":3}' \
  --cmd edit.convertToProfile --params '{"profile":"srgb"}' \
  --out _проба/после.jpg --quality 90
```

Числа подбираются по картинке, а не берутся как есть:

- тени: 10 для слегка тёмных кадров, до 30 для съёмки против света;
- света: 10 обычно, до 40, если белая вещь выбита;
- сочность: только `vibrance`, он бережёт кожу. `saturation` на людях не трогай;
- резкость с порогом 3, чтобы не подчёркивать поры и шум.

Проверь на пробе:

- кожа не стала оранжевой, красной или серой;
- вещь того же цвета, что на исходнике;
- белая ткань с фактурой, чёрная со складками;
- вокруг волос и плеч нет светлой каймы.

Покажи «до» и «после», жди «да». После правок пробу повтори.

## Шаг 4. Горизонт

Заваленный кадр виден по линии пола, плинтусу, дверному проёму. Определи угол на глаз и поверни:

```sh
photocraft-cli commands --filter rotation
photocraft-cli run вход.jpg --cmd image.rotation.arbitrary --params '{"angle":-1.5}' --out _проба/ровно.jpg
```

Параметры поворота сверь по выводу `commands`. После поворота по углам появятся пустые треугольники: обрежь их кадрированием из шага 6. Поворачивай только кадры с заметным завалом, больше одного градуса. Если не уверен в угле, оставь кадр как есть и внеси его в список для человека.

## Шаг 5. Ровный фон, если просили

Подходит для съёмки на однотонном фоне, где фон вышел пятнами или разного тона от кадра к кадру.

1. Возьми цвет фона с лучшего кадра и согласуй его с человеком, например `#d9d9d9`.
2. На пробе:
   ```sh
   photocraft-cli run вход.jpg \
     --cmd layer.removeBackground \
     --cmd layer.newFillLayer.solidColor --params '{"color":"#d9d9d9"}' \
     --cmd layer.arrange.sendToBack \
     --cmd layer.flattenImage \
     --out _проба/фон.jpg --quality 90
   ```
3. Внимательно посмотри на волосы, пальцы, просветы между рукой и телом, тень под ногами.

Честно предупреди: с ровным фоном пропадает естественная тень на полу, и человек может выглядеть наклеенным. Пушистые волосы и прозрачные ткани вырезаются с ошибками. Если на пробе видна вырезанность, не делай этот шаг на партии, а предложи оставить родной фон и только выровнять свет.

## Шаг 6. Кадрирование

Используй способ «Обрезать под пропорцию» из скилла `photocraft-resize-export`. Для фото с человеком:

- голову не резать; если не помещается в рост, режь по середине бедра или по талии, но не по суставам (колени, локти, запястья);
- над головой оставляй воздух около 5–8% высоты кадра;
- вещь, которую показывает кадр, должна быть в кадре целиком;
- у всей серии один и тот же принцип: либо все в рост, либо все по пояс.

## Шаг 7. Партия

Основа лежит в `actions/model-clean.json`. Если числа на пробе менялись, скопируй файл в папку результата и поправь.

```sh
photocraft-cli batch \
  --actions ./готово/_шаги.json \
  --in ./исходники --out ./готово \
  --format jpg --quality 90 \
  --error-log ./готово/_ошибки.txt
```

Поворот и кадрирование делаются по одному фото, после общей партии.

## Шаг 8. Проверка и отчёт

Проверка из раздела 6 базового скилла и дополнительно:

1. Просмотри серию подряд: кожа одного оттенка от кадра к кадру, яркость не прыгает.
2. Отчитайся списком: что применено ко всем, какие кадры повёрнуты, какие кадрированы.
3. Отдельно дай список кадров для ручной доводки: где пыль или пятно на фоне, где не вышел ровный фон, где горизонт под вопросом.
4. Отдельно назови кадры, которые советуешь не публиковать, и причину.
