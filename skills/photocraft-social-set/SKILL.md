# Набор под площадки

Из каждого готового кадра делает несколько версий разного размера. Обрезку считает от главного в кадре: от лица и вещи на фото с человеком, от предмета на предметном фото.

Перед началом прочитай `../photocraft-base/SKILL.md` и `../photocraft-resize-export/SKILL.md`. Способы «вписать с полями», «обрезать под пропорцию» и «только уменьшить» описаны там. Здесь они вызываются по очереди для каждой версии.

## Шаг 1. Что спросить

1. **Какие площадки.** Если человек сказал «под соцсети» и не уточнил, делай три версии: `4x5`, `9x16` и `2000`.
2. **Что делать с кадром, который не помещается в пропорцию.** По умолчанию действуют правила из шага 3.

Лишние версии не делай. Каждая версия это ещё одна папка, которую человеку придётся разбирать.

## Шаг 2. Версии

| Версия | Пропорция | Размер | Куда подходит | Способ по умолчанию |
|---|---|---|---|---|
| `4x5` | 4:5 | 1080×1350 | Лента Instagram, пост ВКонтакте | Обрезать под пропорцию |
| `1x1` | 1:1 | 1080×1080 | Квадратные превью и карусели | Обрезать под пропорцию |
| `9x16` | 9:16 | 1080×1920 | Сторис, обложки рилс и клипов | Обрезать под пропорцию |
| `3x4` | 3:4 | 1200×1600 | Карточка товара на маркетплейсе | Вписать с полями |
| `2000` | как у кадра | длинная сторона 2000 | Telegram, сайт, карточки на картах | Только уменьшить |

Размеры для Instagram совпадают с таблицей официального скилла Adobe для соцсетей. Остальные размеры это разумные значения по умолчанию. Требования площадок меняются: если фото идут на маркетплейс или в рекламный кабинет, попроси человека сверить размер в справке площадки.

## Шаг 3. Посмотри кадр и реши, что в нём главное

Открой кадр и посмотри на него. По имени файла главное не определить.

| Что в кадре | Вокруг чего считать обрезку |
|---|---|
| Человек по пояс или крупнее | Лицо и вещь, которую показывает кадр |
| Человек в рост | Весь человек. Если целиком не помещается, смотри правила ниже |
| Предмет на ровном фоне | Весь предмет с запасом 8% с каждой стороны |
| Раскладка из нескольких вещей | Центр кадра |

Правила для кадров, которые не помещаются:

- Голову не режь никогда. Над головой оставляй воздух 5–8% высоты кадра.
- Человека не режь по суставам: по коленям, локтям, запястьям, щиколоткам. Допустимые линии: середина бедра, талия, середина плеча.
- Вещь, ради которой сделан кадр, остаётся в кадре целиком. Если кадр показывает брюки, обрезка по талии не годится.
- Кадр в рост в версии `4x5` или `1x1`: сначала попробуй обрезку, в которую человек входит целиком. Если не входит, сделай поля цвета фона вместо обрезки.
- Горизонтальный кадр в версии `9x16` обычно теряет больше половины картинки. Не делай эту версию молча: скажи человеку и предложи поля или пропуск.

Поля цвета фона годятся только там, где фон ровный и однотонный. Цвет бери с фона у того края, к которому добавляешь поле, в стороне от человека и теней:

```sh
photocraft-cli run кадр.jpg --cmd document.sampleColor --params '{"x":60,"y":900,"size":31}'
```

Команда ничего не сохраняет. Она печатает четыре числа от 0 до 1: красный, зелёный, синий, непрозрачность. Умножь первые три на 255, округли и запиши как `#rrggbb`. `size` это сторона квадрата в пикселях, по которому берётся среднее: 31 сглаживает зерно бумаги.

На пробе посмотри на границу поля. Если видна ступенька по тону, возьми цвет ближе к краю и повтори. Если ступенька осталась, фон неровный и поля не подходят: пропусти версию для этого кадра и внеси кадр в список.

Скажи человеку одной строкой, что ты выбрал главным и каким способом сделаешь каждую версию.

## Шаг 4. Проба

1. Возьми один типичный кадр. Если в партии есть и вертикальные, и горизонтальные кадры, возьми по одному.
2. Сделай для него все запрошенные версии в папку `_проба`.
3. Посмотри каждую версию своими глазами по правилам шага 3.
4. Покажи человеку пути к файлам и жди «да».

Положение предмета для обрезки узнаётся так же, как в `photocraft-resize-export`:

```sh
photocraft-cli run кадр.jpg --cmd layer.removeBackground
```

В ответе будет `bounds`: `[x, y, ширина, высота]`. На фото с человеком это рамка всей фигуры.

Где лицо, покажет вторая команда. Она тоже ничего не сохраняет и работает без интернета:

```sh
photocraft-cli run кадр.jpg --cmd image.detectFaces
```

В ответе список `faces`, у каждого лица есть `rect`: `[x, y, ширина, высота]` и `score`. Верхняя граница обрезки должна быть выше верха лица на высоту лица: так над головой остаются волосы и воздух. Если лиц не найдено (человек стоит спиной, голова вне кадра), опирайся на рамку фигуры и сдвигай прямоугольник обрезки вверх.

На Windows параметры в строке передавай по правилу из раздела 3 базового скилла.

## Шаг 5. Набор

Три правила на весь набор:

1. **Каждая версия делается из готового кадра полного размера.** Не делай `1x1` из уже обрезанного `4x5`: качество падает с каждым шагом.
2. **Одна папка на версию:** `готово/4x5`, `готово/9x16`, `готово/2000`.
3. **Имя файла:** имя исходного кадра, подчёркивание, версия. Например `IMG_0412_4x5.jpg`. Артикул в имени сохраняется.

Версии с полями и версия `2000` делаются одной командой на всю папку. Файлы шагов лежат в `../photocraft-resize-export/actions/`:

```sh
photocraft-cli batch \
  --actions ../photocraft-resize-export/actions/shrink-long-side-2000.json \
  --in ./обработка --out ./готово/2000 \
  --naming '{name}_2000.{ext}' \
  --format jpg --quality 90 --metadata none \
  --error-log ./готово/2000/_ошибки.txt
```

Шаблон `--naming` задаёт имя файла целиком, поэтому он всегда заканчивается на `.{ext}`.

Для полей не белого цвета скопируй файл шагов в папку результата и замени `"extensionColor": "white"` на цвет фона в виде `"#rrggbb"`.

Версии с обрезкой считаются для каждого кадра отдельно по разделу «Обрезать под пропорцию» скилла `photocraft-resize-export`. Обрезка и точный размер делаются одной командой `image.crop` с `targetWidth` и `targetHeight`. В конце каждой цепочки стоит `edit.convertToProfile` с профилем `srgb`.

Сохранение для всех версий одинаковое: JPEG, качество 90, `--metadata none`.

## Шаг 6. Проверка и отчёт

Проверка из раздела 6 базового скилла и дополнительно:

1. В каждой папке версии число файлов равно числу кадров минус пропущенные.
2. Размер трёх случайных файлов каждой версии через `photocraft-cli info … --compact` совпадает с таблицей до пикселя.
3. Просмотри по четыре файла каждой версии: головы целы, вещи целы, границы полей не видно.

Отчитайся таблицей:

| Версия | Файлов | Способ | Пропущено |
|---|---|---|---|
| `4x5` | 52 | обрезка | 0 |
| `9x16` | 49 | обрезка, 6 с полями | 3 горизонтальных |

Отдельно перечисли кадры, где версия пропущена или сделана с полями, и причину для каждого.
