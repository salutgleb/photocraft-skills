# Для агента

В этой папке лежат скиллы для обработки съёмки одежды, обуви и аксессуаров в редакторе PhotoCraft через утилиту `photocraft-cli`. Три скилла `lightcraft-*` дополнительные: они нужны, только если у человека установлена программа LightCraft с утилитой `lightcraft-cli`. Каждый скилл это папка в `skills/` с файлом `SKILL.md`.

## Если просят установить скиллы

1. Определи папку личных скиллов Codex. По справке это `~/.agents/skills` (в Windows `%USERPROFILE%\.agents\skills`). Более старые версии Codex ставили скиллы в `$CODEX_HOME/skills`, а без этой переменной в `~/.codex/skills`. Если твой собственный установщик скиллов кладёт их в другую папку, клади туда же, куда он. Если набор уже стоит в одной из папок, обнови его там и не создавай вторую копию.
2. Скопируй туда каждую папку из `skills/` целиком, вместе с вложенными `actions/` и `references/`. Папки с теми же именами (`photocraft-*`, `lightcraft-*`, `photoshoot-pipeline`) замени. Другие скиллы в папке не трогай.
3. Проверь `photocraft-cli` по разделу 1 файла `skills/photocraft-base/SKILL.md`. Если утилиты нет, скажи человеку, что скачать и сколько места это займёт. Сам ничего не скачивай без его согласия. `lightcraft-cli` проверь по разделу 1 файла `skills/lightcraft-base/SKILL.md`, только если LightCraft установлен. Если его нет, это не ошибка: не предлагай его ставить.
4. Сверь команды с установленной версией. Набор написан по исходному коду PhotoCraft 0.23.1 и LightCraft 0.21.1 и на живых фото не проверялся, поэтому этот шаг обязателен:
   - `photocraft-cli commands --json` печатает полный список команд установленной версии;
   - выпиши имена команд из файлов `skills/photocraft-*/SKILL.md`, `skills/photocraft-*/references/*.md` и `skills/photocraft-*/actions/*.json` и проверь, что каждая есть в списке;
   - если LightCraft установлен, так же сверь скиллы `lightcraft-*` через `lightcraft-cli commands --json` и имена настроек через `lightcraft-cli controls --json`;
   - если команды нет или её параметры другие, скажи человеку, какой скилл это затронет, и предложи поправить файл скилла по выводу утилиты.
5. Скажи человеку перезапустить Codex и приведи два-три примера, как просить об обработке (они есть в `README.md`).

В macOS и Linux шаги 1 и 2 делает `bash install.sh`. Папку можно назвать явно: `bash install.sh ~/.codex/skills`.

## Если просят обработать фото прямо из этой папки

Скиллы можно читать и без установки: открой базовый скилл нужной программы, затем скилл под задачу.

| Задача | Скилл |
|---|---|
| Вся съёмка от исходников до готовых файлов | `skills/photoshoot-pipeline` |
| Отобрать лучшие кадры | `skills/photocraft-cull` |
| Выровнять свет и цвет, баланс белого по фону | `skills/photocraft-batch-look` |
| Фото на модели: горизонт, кадр | `skills/photocraft-model-retouch` |
| Пятна, складки, тёмные углы бумажного фона | `skills/photocraft-backdrop-clean` |
| Убрать фон, белый фон, карточка товара | `skills/photocraft-product-cutout` |
| Повторить цвет фото-образца | `skills/photocraft-match-style` |
| Набор размеров под несколько площадок | `skills/photocraft-social-set` |
| Один размер, пропорция, вес файла | `skills/photocraft-resize-export` |
| Лист на согласование, пары «до и после» | `skills/photocraft-proof-sheet` |
| Отбор на съёмке больше 150 кадров, если есть LightCraft | `skills/lightcraft-cull` |
| Свет и баланс белого для RAW, если есть LightCraft | `skills/lightcraft-develop` |

Базовые скиллы: `skills/photocraft-base` и, для LightCraft, `skills/lightcraft-base`.

## Правила для любых правок в этой папке

- Тексты скиллов на русском, простыми короткими фразами. Обращение на «ты».
- Имя команды и её параметры пишутся только после сверки с `photocraft-cli commands` или `lightcraft-cli commands`. Непроверенных команд в скиллах быть не должно.
- Числа в файлах `actions/*.json` меняются вместе с таблицами в соответствующем `SKILL.md`.
- Если команда на живом запуске повела себя иначе, чем написано, поправь скилл и справочник `references/commands.md`, а не только свой текущий запуск.
