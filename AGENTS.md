# Для агента

В этой папке лежат скиллы для обработки фото одежды в редакторе PhotoCraft через `photocraft-cli`. Каждый скилл это папка в `skills/` с файлом `SKILL.md`.

## Если просят установить скиллы

1. Определи папку скиллов Codex: `$CODEX_HOME/skills`, а если переменная не задана, `~/.codex/skills` (в Windows `%USERPROFILE%\.codex\skills`). Создай её, если её нет.
2. Скопируй туда каждую папку из `skills/` целиком, вместе с вложенными `actions/` и `references/`. Папки с теми же именами `photocraft-*` замени. Другие скиллы в папке не трогай.
3. Проверь `photocraft-cli` по разделу 1 файла `skills/photocraft-base/SKILL.md`. Если утилиты нет, скажи человеку, что скачать и сколько места это займёт. Сам ничего не скачивай без его согласия.
4. Сверь команды с установленной версией:
   `photocraft-cli commands --filter removeBackground`, затем то же для `canvasSize`, `fitImage`, `trim`, `flattenImage`, `convertToProfile`. Если какой-то команды нет или параметры другие, скажи человеку, какой скилл это затронет.
5. Скажи человеку перезапустить Codex и приведи два-три примера, как просить об обработке (они есть в `README.md`).

В macOS и Linux шаги 1 и 2 делает `bash install.sh`.

## Если просят обработать фото прямо из этой папки

Скиллы можно читать и без установки: открой `skills/photocraft-base/SKILL.md`, затем скилл под задачу. Выбор по задаче:

| Задача | Скилл |
|---|---|
| Убрать фон, белый фон, карточка товара | `skills/photocraft-product-cutout` |
| Выровнять свет и цвет на всей съёмке | `skills/photocraft-batch-look` |
| Размер, пропорция, вес файла | `skills/photocraft-resize-export` |
| Фото на модели | `skills/photocraft-model-retouch` |
| Повторить цвет фото-образца | `skills/photocraft-match-style` |

## Правила для любых правок в этой папке

- Тексты скиллов на русском, простыми короткими фразами. Обращение на «ты».
- Имя команды и её параметры пишутся только после сверки с `photocraft-cli commands`. Непроверенных команд в скиллах быть не должно.
- Числа в файлах `actions/*.json` меняются вместе с таблицами в соответствующем `SKILL.md`.
